For my final design project at Western Canada High School, I designed and built a full-size blackjack table which replaced traditional cards with recycled computer monitors. Further, the project was constructed from reclaimed scrap wood and table felt. This project ran using the HDMI outputs of a laptop, and a blackjack game I designed and programmed from scratch. Despite the large quantity of materials used to create the table, my utilization of recycled wood, table felt, and monitors kept the overall project cost below $50.

The table was named the best project in our class, earning a grade of 100%. Further, the project saw use outside of the classroom as it was used by students in the main lunchroom to play table games.
